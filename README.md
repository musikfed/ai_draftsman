# PEGINELAB AI Draftsman — собственная ИИ-студия

Студия больше не зависит от ComfyUI. Изображения создаёт **изолированный Python Diffusers worker**, а не графовый движок. Flask + обычный HTML/JavaScript работают без PyTorch и не держат видеокарту занятой. Веб-интерфейс — http://192.168.0.100:9898.

## Рабочая конфигурация

- Ubuntu 24.04 / RTX 3060 12 ГБ / NVIDIA 550.163.01 / CUDA 12.4 / Python 3.12.
- Каталог владельца: /1tbdisk/PegineLab/ai_draftsman (не трогать права точки монтирования).
- CPU/RAM/VRAM/swap/диски/зомби — мониторинг только по кнопке.
- Ollama qwen3:8b — черновики 24 уроков и 5 свайпов. SQLite FTS5 — текстовый RAG.
- SDXL Illustrious XL 2.0 — рисунки на GPU через Diffusers, НЕ Ollama.
- Режимы: генерация по описанию / по одному загруженному образцу (img2img).
- 1–3 **альтернативных варианта одного свайпа**, а не 5 альтернативных уроков.
- Выход: 800 × 1000, PNG-8 / до 256 цветов; рядом сохраняется полноцветный PNG.
- Опциональная SDXL-совместимая LoRA из папки models/loras.
- GPU процесс запускается только при заказе изображения; завершает работу после создания вариантов.
- Две кнопки: **Выключить студию** (останавливает Flask) и **Освободить VRAM** (выгружает загруженные модели Ollama при отсутствии активного задания). Кнопки включения нет.
- Интерфейс на 11 языках: ru/en/zh/de/hi/fr/fi/ko/ja/it/be.

## Обновление веб-панели

В терминале, где работает Flask, нажать Ctrl+C, затем:

    cd /1tbdisk/PegineLab/ai_draftsman
    git pull --ff-only
    bash scripts/install.sh
    uv run python -m unittest discover -s tests -v
    bash scripts/run.sh

Не использовать sudo. Запуск веб-панели **не** скачивает модель и **не** загружает GPU.

## Подготовка GPU — один раз, явно

Из другого терминала:

    cd /1tbdisk/PegineLab/ai_draftsman
    bash scripts/install_gpu.sh

Создаётся только runtime/gpu-venv на твоём большом диске. Устанавливаются PyTorch 2.6 CUDA 12.4 и Diffusers. Системные драйверы и Ollama не меняются.

Затем в веб-панели отдельно нажать **Скачать Illustrious XL v2.0** и проверить загрузку кнопкой **Состояние загрузки**. Это модель около 6,94 ГБ, официальный источник https://huggingface.co/OnomaAIResearch/Illustrious-XL-v2.0, лицензия CreativeML OpenRAIL-M. Веса окажутся в models/checkpoints/Illustrious-XL-v2.0.safetensors. Лицензию учитывать при коммерческой публикации.

## Как рисовать

1. Выбрать урок и свайп, составить черновик через Ollama или вписать сценарий и prompt.
2. Проверить канон, перевести слайд в approved, нажать Сохранить.
3. Выбрать **По описанию** или **По образцу**; во втором режиме загрузить референс PNG/JPEG/WEBP.
4. Выбрать число вариантов (1–3), разрешение (768×960 или 896×1120), по необходимости LoRA.
5. Нажать Генерировать кадр. Flask создаст новый job, отдельный worker загрузит SDXL и сохранит результат.
6. Кнопка **Проверить результат** показывает состояние и ссылки на PNG-8. Никакого постоянного опроса браузера.

Изображения и логи: data/jobs/<job-id>/images и worker.log. Генератор не держит тяжёлую модель в фоне; после завершения процесса VRAM освобождается.

## Честные ограничения

Это первая реализация. На Huananzhi результат ещё не проверен: **установка GPU-окружения, первая загрузка Diffusers и реальное качество кадров потребуют теста**. Много-референсная генерация одновременно, обучение собственной LoRA, детерминированный граф канона, векторный RAG, русские реплики поверх пузырей, отбор победителя и автоматический ZIP — запланированы, ещё НЕ реализованы. Само наличие модели не гарантирует постоянство персонажей.

Первая загрузка SDXL из single-file checkpoint может запросить дополнительные конфигурации/токенизаторы с Hugging Face. Весь их кеш размещается внутри data/huggingface проекта на большом диске.

Порт 9898 без авторизации — только для доверенной тестовой LAN.

Смотри docs/ARCHITECTURE.md и docs/WORKFLOWS.md. Прошлый эксперимент ai_video3060_12G закрыт и не является зависимостью студии.
