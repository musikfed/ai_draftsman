# PEGINELAB AI Draftsman

Локальная лёгкая студия для серийных учебных комиксов Karate Linux. Начальный MVP: сценарий из **24 уроков × 5 свайпов**, редактор, граф эпизодов, SQLite FTS5 RAG, Ollama, ручное питание GPU-движка ComfyUI и экспорт PNG-8. UI доступен на **11 языках**: ru, en, zh, de, hi, fr, fi, ko, ja, it, be.

**Статус:** каркас веб-студии находится в репозитории. Реальная модель изображений и ComfyUI на физическом сервере пока **не установлены этим репозиторием**; генерация заработает после настройки совместимого checkpoint и API workflow. UI специально не содержит тяжёлого JS-фреймворка, библиотек визуализации и фонового опроса. Граф 24 уроков — лёгкая кликабельная схема.

## Целевой хост

- Huananzhi X79, Ubuntu 24.04, Python 3.12, uv 0.12.x
- RTX 3060 12GB VRAM, 48GB RAM
- Repository: https://github.com/musikfed/ai_draftsman
- Data / project: любая доступная для записи папка внутри `/1tbdisk` (например, `/1tbdisk/PegineLab/ai_draftsman`, если она доступна текущему пользователю)
- Browser: `http://192.168.0.100:9898`
- Ollama: `http://127.0.0.1:11434` (уже существующий сервис, **не переустанавливаем**)
- ComfyUI: `<каталог_проекта>/runtime/ComfyUI`, порт 8188 *только localhost*
- Flask: порт 9898 доступен в LAN

## Установка панели (без GPU-модели)

Не использовать `sudo` и не менять владельца или права точки монтирования `/1tbdisk`. Ошибка `git clone: Permission denied` означает, что именно место создания каталога недоступно на запись; выбери существующую дочернюю папку с правами своего пользователя (`ls -ld /1tbdisk /1tbdisk/PegineLab /1tbdisk/muzikfed` и `test -w <папка>`). `.env` использует пути `./data` и `./runtime/ComfyUI`, поэтому код переносим между пользовательскими каталогами.


```bash
# Выбрать существующий пользовательский каталог, доступный для записи.
# Например (предварительно проверить: test -w /1tbdisk/PegineLab):
git clone https://github.com/musikfed/ai_draftsman.git /1tbdisk/PegineLab/ai_draftsman
cd /1tbdisk/PegineLab/ai_draftsman
bash scripts/install.sh
bash scripts/run.sh
```

С другого компьютера в домашней сети открыть **http://192.168.0.100:9898**. Панель не имеет тяжёлых клиентских зависимостей и не опрашивает сервер постоянно. Статус обновляется только по кнопке.

В другом терминале можно проверить:
```bash
curl -s http://127.0.0.1:9898/api/status
```

Для выключения **веб-панели** остановить foreground-процесс (Ctrl+C) в том терминале, где запущен `bash scripts/run.sh`. ВКЛ/ВЫКЛ в UI относятся к **GPU-движку ComfyUI**, а не ко всему веб-приложению.

## Интеграция GPU и графической модели

Нужен ComfyUI с собственным Python venv, рабочая CUDA-сборка PyTorch и checkpoint. На RTX 3060 12GB для манги рекомендуем начать с совместимой **SDXL / Illustrious XL** модели и после проверки использовать LoRA персонажей. Более требовательные модели можно тестировать с `--lowvram` и выгрузкой в RAM. Существующий NVIDIA 550 driver сначала проверить на совместимость с выбранной сборкой PyTorch; **не обновлять драйвер автоматически** на работающем сервере.

Подробно: [docs/WORKFLOWS.md](docs/WORKFLOWS.md).

В UI:
1. Настроить реально работающий workflow в ComfyUI и экспортировать `API Format` в `data/workflows/comic_api.json`, подставив `{{PROMPT}}` в одно поле text.
2. Кнопкой **ВКЛ** поднять свой ComfyUI, или **ВЫКЛ** остановить только тот процесс, который стартовал Draftsman.
3. **ИИ: набросать 5 свайпов** вызывает локальную Ollama (qwen3:8b), строго создавая 5 черновиков.
4. Поочерёдно отредактировать и утвердить каждую страницу, затем отправить её в ComfyUI.
5. Изображение обработать: `uv run python scripts/export_png8.py source.png output.png`. Получится 800×1000, индексированные 256 цветов.

Планы/черновики и RAG лежат в `data/draftsman.db`, комиксный канон в `canon/karate_linux.json`.

## Не загружает GPU без команды

- Flask, SQLite и интерфейс почти не используют GPU.
- При старте панели ComfyUI **не запускается**.
- Ollama вызывается только на запрос планирования; `keep_alive: "0s"` просит выгрузить модель после ответа.
- Кнопка ВЫКЛ не убивает Ollama, Xorg, другие Docker-процессы или чужие инстансы ComfyUI.
- При наличии активной очереди ComfyUI команда остановки будет отклонена.

## Безопасность тестового LAN

В первой версии нет авторизации: **только для доверенной изолированной домашней сети**. Не публиковать :9898 наружу и не делать port forwarding. Приложение не обращается к системным сервисам кроме принадлежащего ему ComfyUI.
