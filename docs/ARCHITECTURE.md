# PEGINELAB AI Draftsman — архитектура без графового генератора

Основной принцип: **без постоянно работающего GPU-сервиса**. Пользователь открывает Flask-панель на LAN:9898; Ollama по запросу составляет пять последовательных слайдов; Diffusers запускается по нажатию Генерировать кадр в краткоживущем Python-процессе. После генерации процесс завершается, оставляя мастер PNG и PNG-8.

## Существующие компоненты

1. Flask и vanilla HTML/JS на LAN:9898, 11 языков, без сборщиков и непрерывного опроса.
2. Canon JSON: 24 урока и пять слайдов на урок; SQLite: сценарии, prompt, approved, FTS5 text RAG; Ollama: Qwen3:8B структурированный черновик.
3. Системный мониторинг CPU/RAM/VRAM/swap/диски/zombie по запросу; библиотека локальных checkpoint.
4. Студия запускает отдельный процесс studio.worker через studio.jobs, только по утверждённому промпту.
5. SDXL Illustrious XL 2.0 в models/checkpoints + опциональная SDXL LoRA в models/loras. GPU PyTorch/CUDA библиотеки изолированы в runtime/gpu-venv.
6. text2img / image2img по одному референсу, 1–3 варианта одного слайда, 768×960 или 896×1120 исходник, экспорт 800×1000 PNG-8 + полноцветный master.
7. Веб-кнопка Проверить результат с JSON-статусом и ссылками на изображения. Нет постоянного VRAM использования вне конкретного задания.
8. Кнопки Выключить студию (только Flask) и Освободить VRAM (выгрузка модели из Ollama только если нет активного job).

## Логическая схема

Браузер → Flask → {SQLite/Canon, Ollama → утверждение сценария} → Job JSON → отдельный PyTorch Diffusers worker → варианты PNG → ручной выбор → будущая сборка ZIP.

Директории: data/jobs, data/references, data/huggingface, models/checkpoints, models/loras, runtime/gpu-venv; всё внутри /1tbdisk/PegineLab/ai_draftsman. Драйвер NVIDIA, системная Ollama, Docker, VPN и другие проекты не изменяются.

## Будущие компоненты (НЕ реализованы)

- Отдельные сущности characters, scenes, graph_edges для связанного сюжета и фиксированных поясов.
- Гибридный RAG с nomic-embed-text + SQLite embeddings/sqlite-vec; визуальная индексация референсов по CLIP/SigLIP.
- Управление несколькими референсами с совместимыми адаптерами и control signals.
- Обучение собственных LoRA Грепа/ROOT/слона по выбранным авторским образцам.
- Автоматический Letterer для русских реплик и правильных команд.
- Контроль качества композиции и канона с возможностью ручного утверждения.
- Автоматический ZIP с пятью разными последовательными страницами на урок.

Без всех этих частей генератор не может гарантировать полную консистентность образов на 120 страницах. Цель первой версии — **сначала реально нарисовать на RTX 3060 один кадр без тяжёлой UI-надстройки**, затем развивать студию.
