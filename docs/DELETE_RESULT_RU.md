# Удаление отдельного результата AI Draftsman

Во вкладке **«▣ Результаты»** на каждой карточке рядом с «Черновик» находится красная кнопка **«Удалить»**.

**Что происходит при подтверждении:**

- Удаляется **только выбранный вариант** рисунка с постоянным индексом вида `R-000002`.
- Из каталога SQLite исчезают его запись `quick_result_index` и оценка `quick_image_ratings`. Если это последний рисунок задания, удаляется также пустая связь `quick_draft_jobs`.
- В `data/jobs/<job-id>/state.json` убирается выбранный элемент `outputs` (и фиксируется номер удалённого варианта).
- С диска удаляются его обычный PNG-8 и полноцветный `*_master.png`, чтобы освободить место. Остальные варианты того же задания остаются.
- Галерея, последние эскизы и окно просмотра обновляются; при следующем F5 удалённый вариант не появится снова.
- **Черновик, его перевод, оценки других рисунков, конфигурация `spec.json`, `worker.log`, checkpoint, LoRA и референсы не удаляются.** Это позволяет сохранить текст и историю эксперимента.

**Защита:** повторное удаление возвращает 404. Нельзя удалять результат работающей/поставленной в очередь GPU-задачи. **Архив только для чтения** защищён от удаления — его сначала нужно вернуть из архива. Сервер проверяет, что PNG находится именно в `data/jobs/<job-id>/images/` и не является символической ссылкой.

Для безопасности файлы сначала временно перемещаются в `.delete-staging` внутри папки задания. После обновления `state.json` и фиксации SQLite они удаляются окончательно. При ошибке записи в базу или манифест студия пытается восстановить прежние файлы и запись; при сбое очистки сообщение укажет на оставшиеся временные файлы.

API: `DELETE /api/quick/results/<result-id>`.

Удаление необратимо, поэтому требуется явное подтверждение. **Архивирование** — безопасный вариант, если нужно лишь скрыть/защитить результат, не освобождая диск.

## Обновление сервера

После завершения GPU-рендера:

```bash
cd /1tbdisk/PegineLab/ai_draftsman
# В окне работы Flask сначала Ctrl+C
git pull --ff-only
uv run --no-sync python -m unittest discover -s tests -v
bash scripts/run.sh
```

Затем **Ctrl+F5** в браузере. Новые службы и пакеты для удаления не требуются.
