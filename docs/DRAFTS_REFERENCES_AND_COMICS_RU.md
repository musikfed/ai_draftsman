# Черновики, референсы и восстановление настроек — AI Draftsman

## Где лежат данные

- Последний быстрый промпт: таблица `quick_draft` в `data/draftsman.db` (или в каталоге `DRAFTSMAN_DATA`).
- **Сохранённые версии** после обновления: таблица `quick_draft_history`. Для каждой версии хранятся исходный положительный/негативный промпты, необязательные переводы на русский и дата сохранения.
- Готовые задачи: `data/jobs/<job-id>/spec.json`, `state.json`, `worker.log` и изображения в `images/`.
- Загруженные изображения-образцы: `data/references/<uuid>.png`; эти копии отделены от исходных файлов на компьютере и готовых результатов.
- Локальные настройки формы: `localStorage` браузера, который открывает веб-студию. Очистка данных сайта может их удалить, но уже сохранённая SQLite-история и задачи останутся на сервере.

## Как открыть черновики и получить перевод

1. Перейди в **«Быстрый рисунок — без графа»**, нажми **«Сохранить черновик»**. Повторное сохранение тех же текстов подряд не создаёт лишнюю версию.
2. Открой **«Библиотека черновиков»** под кнопкой сохранения, выбери версию из списка.
3. **«Загрузить в поля»** восстанавливает оба исходных промпта, но не запускает рендер и не перезаписывает другие версии.
4. **«Перевести на русский»** отправляет *копии* обоих текстов в выбранный локальный Ollama/Qwen и сохраняет полученные переводы рядом с оригиналом. Кнопка не активирует GPU-рендер, но перевод во время активной генерации запрещён, чтобы не конкурировать за VRAM. Смысл перевода может требовать ручной проверки.
5. **«↻ Список»** обновляет библиотеку. Старая таблица `quick_draft` не удаляется: её последний существующий текст при первой миграции переносится как начальная версия, если история пуста.

## Куда нажать для работы по образцу

**Разные вещи:** «Выберите файл» только выбирает файл *на компьютере* и **не добавляет его в студию**. Поэтому даже после выбора файла список может показывать «Без референса».

1. Справа нажми **«Выберите файл»**, укажи JPG/PNG/WebP и обязательно **«Добавить образец»**.
2. После успешной загрузки должен появиться миниатюрный просмотр и выбор сохранённого файла в меню **«Изображение-образец»**. Режим автоматически переключится на **«По образцу»**.
3. Оставь **«Без LoRA»**, если не используешь адаптер, или выбери совместимый.
4. Для первого теста сохраняющей композицию генерации установи **strength 0,25–0,35**, **Steps 28**, **CFG 5,5–6,5**, **вариантов 1**, базовый SDXL или Illustrious по стилю. Чем сильнее strength, тем активнее модель отходит от исходного изображения. Этот режим **не гарантирует** сохранение лиц, точных панелей комикса или текста.
5. Нажми **«Генерировать»**. При необходимости **«Удалить образец»** удалит только загруженную копию после подтверждения; при активном рендере удаление блокируется.
6. **«↺ Сбросить параметры»** возвращает значения генерации по умолчанию, отключает референс и LoRA. Черновики, рисунки, проекты и скачанные модели **не удаляются**.

## Почему комикс KARATE LINUX не повторился

Проверь положительный и отрицательный промпты: нельзя одновременно требовать **comic panels / terminal windows / Linux symbols** и запрещать их фразами **no comic book panels / no tech elements / no Linux logos or symbols**. Студия теперь предупреждает о нескольких таких явных противоречиях перед отправкой задания.

Также следует различать:
- **txt2img:** выбранный в проводнике файл никак не влияет на генерацию;
- **img2img:** изображение используется как стартовая композиция, но *не* как обучающая выборка;
- **LoRA:** отдельно обученный адаптер, не обязателен и не восстанавливает текстовые реплики автоматически;
- **Контроль сюжета/композиции:** для точного повторения панелей понадобятся отдельная вёрстка, ControlNet/маски/разбиение по кадрам или другие специализированные механизмы.

Для иллюстрации KARATE LINUX попробуй **один кадр**, а не три одновременно. Положительный промпт:

```text
One dramatic vertical comic illustration of Grep Pipe, a young man without a beard,
wearing a black PL baseball cap, orange glasses and a black-and-orange technical
jacket, performing a karate move in front of Sensei ROOT, an anthropomorphic
penguin in a black kimono. Energetic arcade fighting-game composition,
expressive manga linework, vibrant orange accents, coherent anatomy,
clear silhouette, detailed background, no lettering or speech bubbles.
```

Негативный промпт:

```text
beard, wrong character costume, white karate gi on the protagonist,
extra arms, extra legs, deformed hands, merged characters, unreadable text,
watermarks, duplicate faces, low detail, blurry, blurry background
```

**Затем** реплики и рамки панелей собирать отдельно. Изобразить надёжно читаемое «uname -r» или Linux-команду прямо внутри генерации SDXL обычно трудно. Готовая страница KARATE LINUX — это задача композиции из нескольких изображений, а не одного txt2img запроса.

## Проверка на Huananzhi

```bash
cd /1tbdisk/PegineLab/ai_draftsman
git pull --ff-only
bash scripts/run.sh
```

Не обновляй сервер во время активной генерации. Перезапуск — вручную после Ctrl+C, никакого systemd. Для текущих данных не надо переустанавливать SDXL.

При ошибках API из браузера можно проверить (из терминала сервера):

```bash
curl -s http://127.0.0.1:9898/api/quick/drafts
curl -s http://127.0.0.1:9898/api/references
```
