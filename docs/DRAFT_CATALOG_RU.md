# AI Draftsman — каталог черновиков и результатов

## Как открыть

В режиме «Быстрый рисунок — без графа» раскрой **«📚 Каталог черновиков · поиск, перевод, рисунки и оценки»**.

- Поиск по названию, положительному и негативному промптам, русским переводам и заметкам
- Сортировка: новые, старые или лучшие; фильтр по оценке
- Перелистывание по 8 записей
- Карточка: оба промпта, сохранённый русский перевод, название, оценка, заметка
- Связанные картинки из реально завершённых генераций с полноразмерным просмотром и оценкой каждого результата от 1 до 5
- «Загрузить текст в редактор» восстанавливает оба промпта без запуска GPU и без изменения старых сохранённых версий

Фильтр «С изображениями» в этой версии показывает черновики с привязанными заданиями, среди которых могут быть неуспешные. Миниатюры появляются только для существующих PNG.

## Сохранение и перевод

Последний редактируемый текст по-прежнему хранится в SQLite quick_draft и локально в браузере. Новые версии сохраняются отдельно в quick_draft_history и никогда не заменяются одним текущим черновиком. При обновлении схема SQLite только расширяется; старые записи не удаляются.

При ручном сохранении студия автоматически инициирует перевод на русский (если он нужен и ещё не сохранён). Русский оригинал не требует модели. Идентичные ранее переведённые тексты переиспользуют существующий перевод. Английские тексты переводятся одним запросом к локальному Qwen; обе версии перевода хранятся рядом с оригиналом в SQLite. После ошибки новая попытка откладывается на час, чтобы не мучить модель. Если работает GPU-рендер, перевод откладывается. При просмотре записи студия проверяет его автоматически.

Перевод — для понимания текста, не для замены рабочего промпта, и может содержать неточности.

## История генераций

SQLite: data/draftsman.db. Связи между черновиками и заданиями: quick_draft_jobs; отдельные оценки PNG: quick_image_ratings. Реальные файлы: data/jobs/<job-id>/spec.json, state.json, images/. При первом запуске обновлённой версии происходит однократная привязка старых быстрых генераций к сохранённым промптам по точному совпадению текста; если черновика нет, он создаётся из сохранённой спецификации задания. Данные не перезаписываются.

Сохранённые тексты независимы от PNG. Один промпт может иметь много связанных рисунков. Для повторения похожего кадра нужны не только текст, но и модель, seed, размер, CFG, Steps и при необходимости референс/LoRA.

## Черепаха

SVG static/images/sea-turtle-cartoon.svg перерисован с более крупной улыбающейся мордочкой, голубыми глазами, широкими ластами и узорным оранжево-коричневым панцирем. Ласты — цельные формы, а суставы закрываются туловищем. Анимация CSS внутри SVG; React, GIF, лишние службы или GPU не нужны. Внешний вид проверь кнопкой «🌊 Демо ожидания».

## Обновление и проверка

После окончания генерации — Ctrl+C в текущем терминале Flask:

```bash
cd /1tbdisk/PegineLab/ai_draftsman
git pull --ff-only
uv run --no-sync python -m unittest discover -s tests -v
bash scripts/run.sh
```

В браузере Ctrl+F5. Другие службы, установленные SDXL-модели и старые изображения не затрагиваются.
