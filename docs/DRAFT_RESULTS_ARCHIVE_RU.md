# AI Draftsman — черновики, результаты и архив (21 ноября 2026)

## Три рабочих режима

**⚡ Быстрый рисунок** — редактор положительного и негативного промптов; справа настройки SDXL, Illustrious, LoRA и img2img. Здесь сверху показываются 8 последних эскизов, с обновлением после новой генерации и при открытой видимой вкладке примерно раз в минуту.

**▣ Результаты** — отдельная вкладка с поиском, постоянным индексом вида R-000001, понятным названием, миниатюрой готового рисунка, датой, Seed и привязкой к черновику. Есть пагинация, сортировка, фильтр архивных и активных работ, открытие результата, переход к исходному черновику и перегенерация.

**◈ Проекты и граф** — прежний редактор долгих проектов; его логика и графические задания не изменялись.

## Работа с черновиками

1. Заполни промпт и негативный промпт, нажми «Сохранить черновик». Старое поле последнего текущего текста обновляется, но отдельные версии в quick_draft_history сохраняются, не удаляются.
2. Раскрой «📚 Каталог черновиков» под редактором: поиск по названию, оригинальному тексту, русскому переводу, негативному промпту, заметкам или номеру (например #17). Листай страницы кнопками ← и →.
3. Выбери черновик. Откроются исходные тексты, два русских перевода, оценка, заметка и подлинные сохранённые результаты PNG. Можно оценивать каждую картинку отдельно.
4. «Загрузить текст в редактор» восстанавливает оба исходных промпта, не изменяя найденную запись. «Перегенерировать» создаёт новую версию и одно GPU-задание; доступно и для архивного источника.
5. «В архив · только чтение» фиксирует черновик и связанные результаты. Редактирование названия, заметки, оценки черновика и оценки его изображений блокируется. Поиск по архиву сохраняется; специальная кнопка «Вернуть из архива» явно разблокирует запись.

## Повтор генерации

По кнопке «Перегенерировать · новый Seed» повторно используется сохранённое описание, негативный промпт и доступные настройки последнего задания (checkpoint, CFG, Steps, разрешение, режим, сила img2img и LoRA). Новый Seed создаёт новый вариант.

«Повторить · прежний Seed» использует ранее сохранённый Seed, чтобы сравнение было более предсказуемым. Совпадение картинки пиксель в пиксель не гарантируется, если изменились версии библиотек или модели.

**Каждая повторная генерация создаёт новую версию черновика** с parent_draft_id. Исходный архив не изменяется. Для экономии GPU всегда запускается один вариант, даже если исходно их было много. Если исходный файл img2img или LoRA удалён, API честно сообщает об отсутствии файла; не подменяет молча режим.

## Перевод и локальные модели

Переводы сохраняются в SQLite, как справочная информация к английскому тексту. Для одинаковых промптов используется уже сохранённый перевод. Русскоязычный промпт не заставляет Qwen переводить сам себя. При активном GPU-рендере перевод откладывается; при следующем просмотре черновика проверяется снова. Повтор после ошибки ограничен одним запросом в час на запись. Новых фоновых systemd-сервисов не устанавливается.

## Хранение и экономия места

data/draftsman.db хранит текст, перевод, название, оценки, индекс и связи. Оригинальные результаты остаются в data/jobs/<job-id>/images/, настройки каждого задания — в spec.json, статус — в state.json. Веб-галерея и главные эскизы читают эти файлы по URL /api/jobs/<job-id>/images/<variant>.

**Вторых копий PNG ради эскизов не создаётся.** Превью на главной заменяется более свежим после перегенерации. При этом старые генерации физически остаются на диске, чтобы их можно было сравнивать. Экономится место в интерфейсе и объём дополнительных копий, но не пространство уже созданных файлов. Автоматического удаления старых результатов нет — это было бы небезопасно без отдельного согласия.

Индексы R-000001... назначаются один раз при обнаружении существующего изображения и затем остаются постоянными. Старые быстрые генерации однократно связываются с черновиками по точному тексту, без удаления имеющейся базы.

## Обновление на Huananzhi

После окончания активной генерации остановить Flask через Ctrl+C, в каталоге /1tbdisk/PegineLab/ai_draftsman выполнить git pull --ff-only, затем uv run --no-sync python -m unittest discover -s tests -v и bash scripts/run.sh. В браузере обновить Ctrl+F5. Ни GPU worker, ни Ollama, ни установленные SDXL/LoRA обновлять или скачивать заново не нужно.
