# Каталог промптов с реальными примерами и мультяшная SVG-черепаха

## Каталог: что считается примером

В режиме **«Быстрый рисунок — без графа»** раскрой раздел **«Каталог промптов с реальными примерами изображений»**.
Каталог берёт **только завершённые генерации** из файлов `data/jobs/<job-id>/spec.json` и `state.json` с настоящими PNG, а не придумывает предполагаемую картинку по тексту.

Для каждой карточки доступны:
- миниатюра действительного результата;
- точные **положительный и негативный промпты**;
- **SDXL checkpoint**, Seed использованного варианта, Steps, CFG, разрешение, LoRA;
- режим txt2img/img2img и Strength (если использовался образец).

**«Загрузить промпт и настройки»** переносит текст и параметры в поля формы, но **не запускает генерацию**.
Встроенная **«Библиотека черновиков»** остаётся отдельной: это версии текста и переводы на русский, даже если рисунок ещё не получился.

### Почему не обязательно получим тот же кадр

Текст не задаёт все случайности и детали модели. Для максимально близкого повторения нужны один и тот же checkpoint, положительный/негативный промпты, Seed, Steps, CFG, размеры, pipeline и настройки окружения. Для img2img также нужен **тот же исходный образец** и strength. LoRA должна быть той же самой. После обновления библиотек, оборудования и GPU результаты могут немного различаться.

Если из студии удалили исходный референс или LoRA, кнопка каталога **не утверждает, что условия восстановлены**: она переключает на режим по описанию или отключает отсутствующий адаптер и предупреждает. Созданные изображения остаются в истории.

Каталог показывается только при открытии раздела: **никаких постоянных фоновых запросов, скачивания моделей и расхода GPU**.

## SVG-черепаха

Создана **оригинальная** мультяшная морская черепаха, ориентированная на пожелания пользователя: улыбающаяся мордочка, голубые глаза, оранжево-коричневый панцирь с сегментами, зелёные ласты, чешуйки, мягкие градиенты.

Файл: `static/images/sea-turtle-cartoon.svg` (менее 12 КБ). Полностью векторный, **без React**, GIF, JavaScript-таймеров, дополнительных библиотек, сетевых запросов или GPU. Исходный водяной знак с чужого примера не копировался, рисунок создан с нуля.

Анимация работает через встроенные CSS `@keyframes` в SVG: передние ласты поворачиваются **независимо** вокруг скрытых под телом оснований; задние слегка помогают. Никаких разрывов наложенными масками PNG/WebP. Изображение целиком медленно плавает поверх прежнего подводного фона в ожидании. Поддерживается `prefers-reduced-motion`.

Проверка: открой веб-студию и нажми **«🌊 Демо ожидания»** — без рендера SDXL. Параллельно можно открыть сам SVG в браузере, чтобы проверить анимацию отдельно.

## Запуск обновлений

После окончания активной GPU-генерации в терминале Flask нажми Ctrl+C, затем:

```bash
cd /1tbdisk/PegineLab/ai_draftsman
git pull --ff-only
uv run --no-sync python -m unittest discover -s tests -v
bash scripts/run.sh
```

Новые службы/systemd/React не устанавливаются. Для новых функций используется существующая история задач, новые таблицы SQLite не требуются.
