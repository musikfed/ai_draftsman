# AI Draftsman — собственный GPU-движок Diffusers

## Принцип

Графического сервера постоянно нет. Flask 9898 работает как лёгкая панель. На каждый запрос создаётся Python-процесс из отдельного runtime/gpu-venv; он загружает Illustrious XL, строит 1–3 варианта и завершается, автоматически освобождая CUDA контекст.

Веб-браузер не выполняет ни инференс, ни подбор весов, ни обучение.

## Физический компьютер

RTX 3060 12GB, NVIDIA 550.163.01 с CUDA Driver API 12.4, Ubuntu 24.04, Python 3.12, RAM 48 GB. Установку GPU-пакетов делаем только в runtime/gpu-venv на диске /1tbdisk. Скрипт scripts/install_gpu.sh использует официальные колёса PyTorch 2.6.0 CUDA 12.4. Не меняет драйвер и не переустанавливает Ollama.

1. Остановить Flask (Ctrl+C), обновить проект git pull --ff-only, bash scripts/install.sh, проверить тесты.
2. При желании вручную выполнить bash scripts/install_gpu.sh.
3. Из веб-панели по отдельной кнопке скачать Illustrious XL 2.0 (официальный Hugging Face, примерно 6.94 GB). Скачивание не стартует самостоятельно.
4. Выбрать урок и слайд; сформировать и утвердить prompt. Греп/ROOT/слон — по утверждённому канону.
5. Режим txt2img создаёт кадр по тексту; режим img2img использует одну загруженную картинку из data/references. Три варианта — три разных seed одного свайпа.
6. Создать задание и нажимать Проверить результат вручную. Полноцветный master PNG и итоговый PNG-8 800×1000 сохраняются в data/jobs/<id>/images.
7. Варианты не являются следующими свайпами. Выбранный вариант пользователь утверждает отдельно (автоматическая сборка ZIP пока в планах).

## LoRA

Если готова своя SDXL-LoRA персонажа, её можно положить в models/loras и выбрать в редакторе. Обучение LoRA ещё не подключено. Не смешивать SDXL-LoRA и адаптеры других базовых моделей.

## Память

Каждая генерация загружает модель с CPU offload, поэтому первые секунды/минуты при работе старых Xeon и DDR3 могут быть долгими. Одновременно разрешено одно GPU-задание. При успешном завершении процесс выходит; память освобождается независимо от кнопки VRAM. Кнопка Освободить VRAM предназначена для выгрузки неактивных моделей Ollama; она не прерывает текущий GPU-рендер.

Возможные ошибки CUDA/PyTorch/памяти фиксируются в data/jobs/<id>/worker.log и status=failed; картинки при неуспехе не обещаются. В случае OOM сначала пробовать 768×960, один вариант, без LoRA и параллельных Ollama-инференсов.

## Ограничения MVP

Векторный RAG, полноценный узловой граф, несколько одновременных графических референсов, автоматическая проверка поясов, набор русских облачков, LoRA training и ZIP пока не реализованы. Русский текст на иллюстрациях лучше наносить отдельно; Diffusers не гарантирует правильную кириллицу.

Поиск моделей и запуск инференса выполняются только по явным нажатиям. Никаких резервных копий или изменений других проектов.
