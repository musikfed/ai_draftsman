# Работа в универсальной PEGINELAB AI Draftsman

1. **Проект**: нажми «+ Новый проект», укажи название. Граф изначально пустой. Для Karate Linux существует отдельная кнопка шаблона.
2. **Настройки проекта**: раскрой блок; описание цели, общий стиль, negative prompt, системная инструкция для агента и модель Ollama.
3. **Граф**: тип узла выбирается справа от заголовка графа. Добавь узлы и перетаскивай. Выбери исходный узел, целевой в списке и нажми «Добавить связь».
4. **Узел**: название, тип, что происходит, собственные positive/negative prompts, статус draft/approved. Сохранение вручную.
5. **LLM**: «ИИ: составить промпт» использует описание проекта, связанные узлы, текстовый RAG и выбранную модель Ollama. Результат остаётся черновиком, пока не утвердишь.
6. **Модели**: «Показать установленные» не скачивает. «Скачать LLM» через Ollama вручную и отдельный «Статус загрузки». На хосте уже есть qwen3:8b и qwen3:4b-instruct. Проверяй место хранения Ollama: системный раздел почти заполнен.
7. **Картинка**: для утверждённого узла укажи mode txt2img/img2img, 1–48 вариантов, параметры Steps/CFG/Seed и другие. При нажатии запускается краткоживущий GPU-процесс Python Diffusers.
8. **Результат**: «Проверить результат» — без постоянного фонового опроса. Показ PNG-8 800×1000 и исходного master в каталоге jobs.
9. **Состояние сервера**: верхний мониторинг свёрнут. При раскрытии и ручном обновлении показывает CPU/RAM/VRAM/SWAP/диски/зомби.

Для запуска:
```bash
cd /1tbdisk/PegineLab/ai_draftsman
git pull --ff-only
bash scripts/install.sh
uv run python -m unittest discover -s tests -v
bash scripts/run.sh
```

Комиксный шаблон не ограничивает остальные проекты. Прототип собственного GPU-рендера требует отдельной установки через `bash scripts/install_gpu.sh` и загрузки графической модели; никаких ComfyUI и постоянной GPU-службы нет.
